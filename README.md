# BDS Backup Drive

Public information and privacy-policy website for Boyd Digital Studios' internal encrypted backup utility.

## Publishing status
The site source is served by GitHub Pages from the dedicated public repository's `main` branch (`/(root)`). On 6 November 2026, the owner's GitHub Pages screenshot showed a **successful DNS check** for `backups.uapdisclosuredesk.com`, but **HTTPS certificate issuance remained pending**. Public HTTPS availability must be confirmed separately in Pages settings and by loading both URLs; a green DNS check alone does not prove HTTPS is live.

- Homepage: https://backups.uapdisclosuredesk.com/
- Privacy policy: https://backups.uapdisclosuredesk.com/privacy/

This branch stages public copy accuracy fixes only. It is **not** the GitHub Pages publishing branch and changes here will not affect the published pages until explicitly merged or copied to `main`.

Only public website files belong here. The operational backup runner, encryption keys, OAuth tokens, database credentials and encrypted customer archives must stay outside this PUBLIC repository.
